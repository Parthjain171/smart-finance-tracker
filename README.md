# 💰 Smart Finance Tracker

A modern AI-powered personal finance tracker that converts natural language into structured financial insights.  
It helps users track income, expenses, and pending transactions while providing intelligent analysis of spending behavior.

---

## 🚀 What it does

- 🧠 Add expenses using natural language (e.g., “Spent 500 on food yesterday”)
- 💬 Chat-based transaction input
- 📊 Auto-generated financial dashboards
- 💡 Smart insights on spending habits
- 📅 Flexible time-based analytics (monthly, yearly, custom)

---

## ✨ Key Features

### 🤖 Smart Input System
- Natural language transaction entry  
- Automatic detection of amount, date, and category  
- Chat-like experience for fast data entry  

---

### 💸 Expense Management
- Track income, expenses, and pending transactions  
- To Pay / To Receive system  
- Structured categorization with clean organization  

---

### 📊 Analytics Dashboard
- Income vs expense comparison  
- Category-wise breakdown  
- Monthly and weekly trends  
- Top spending sources  

---

### 💡 AI Insights
- Spending behavior analysis  
- Weekend vs weekday patterns  
- Fixed vs variable expense detection  
- Personalized financial suggestions  

---
