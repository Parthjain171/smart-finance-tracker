💰 Smart Finance Tracker

A modern AI-powered personal finance tracker that turns natural language into structured financial insights.
Track income, expenses, and pending transactions while getting intelligent insights about your spending behavior.

🚀 What it does
🧠 Add expenses using natural language (e.g., “Spent 500 on food yesterday”)
💬 Chat-based transaction input
📊 Auto-generated financial dashboards
💡 Smart insights on spending habits
📅 Flexible time-based analytics (monthly, yearly, custom)
✨ Key Features
🤖 Smart Input System
Natural language transaction entry
Auto-detection of amount, date, and category
Chat-like experience for fast input
💸 Expense Management
Income, expenses, and pending transactions
To Pay / To Receive tracking
Structured categorization system
📊 Analytics Dashboard
Income vs Expense trends
Category-wise breakdown
Monthly and weekly analysis
Top spending sources
💡 AI Insights
Spending behavior analysis
Weekend vs weekday patterns
Fixed vs variable expense detection
Personalized financial suggestions
⚙️ Tech Stack
Python
Streamlit
Pandas
Plotly
Google Sheets API
Gemini AI
🚀 Setup
git clone https://github.com/Spritan/expense_tracker
cd expense_tracker
pip install uv
uv sync
Run app
uv run streamlit run Home.py
🔐 Environment Variables
GOOGLE_SHEETS_CREDENTIALS=your_credentials.json
GOOGLE_SHEET_ID=your_sheet_id
GEMINI_API_KEY=your_api_key
🎯 Purpose

This project is built to simplify personal finance tracking using AI and make financial awareness accessible through automation and analytics.
